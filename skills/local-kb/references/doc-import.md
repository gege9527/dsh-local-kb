# 文档模式（导入）

只收**本地文件**与**粘贴内容**（网页先落成本地文件）。知识库只存文本，不收图片二进制。

## 先判：值不值得存

**拒**（存了也没法用）：

- 抓不到正文的：登录页、纯导航页、正文为空、纯图片、需鉴权才能看的内容
- 与已有文档同 `source` 或同标题 —— 改走「刷新」，不新建

**不拒**：

- "能在线取到"**不是**拒收理由。默认存全文，`source` 留原链接。
  链接会失效、源站会改版、断网也要能查 —— 本地化是第一优先。

**存档类 vs 结论类**（影响下面要不要写结论块）：

| 类型 | 例子 | 正文要求 |
|---|---|---|
| 存档类 | 官方文档、API、规范 | 概览 + 保留原层级即可 |
| 结论类 | 逆向分析、调研、方案、会话产出 | 建议三块：概览 / 关键结论或步骤 / 限制与前提 |

结论类没有「限制与前提」就是残缺：适用范围、版本、已知坑至少写一句，没有就写"无"。

## 本地化策略

1. **默认存全文**，不改写成摘要
2. `source` 必填：原始路径 / URL / "会话产出"
3. **查询时不联网、不比版本**：本地正文就是答案，回答里带一行「快照 <date_added>（<N> 天前）」。
   `age = 今天 − (last_checked || date_added)`；`age ≥ 90` 才补一句「可能过时；要核对说『刷新这篇』」。
   不用版本号判据——多数文档没有 `doc_version`，纯时间即可。
4. **回源只在用户明确要求时**（「核对最新」「刷新这篇」「更新这篇」）：抓一次 → 给 diff 摘要
   （版本号 / 章节 / 接口签名变化）→ 问「覆盖 / 只记结论 / 取消」。查询流程本身永不抓取。
5. `source` 非 URL 的文档（本地文件/会话产出）无法回源：只标注「本地快照，无更新来源」，不催刷新。
6. 同一份内容在库里只留一份；新版覆盖旧版，不并列

## 步骤 1 — 接收与转换

| 输入 | 处理 |
|---|---|
| `.md` / `.txt` / `.csv` / 代码文件 | 直接读取，原样或轻整理 |
| `.html` | AI 读原文，剥离标签转干净 Markdown（保留标题层级、代码块语言） |
| `.docx` | 标准库解包提取：`python3 -c "import zipfile,re,sys; x=zipfile.ZipFile(sys.argv[1]).read('word/document.xml').decode('utf8'); print(re.sub(r'<w:p[ >]', '\\n', re.sub(r'<[^>]+>', '', x)))" <文件>` |
| `.odt` | 同上，取 `content.xml` |
| `.pdf` | 优先 `pdftotext <f> -`（若系统有）；无则 AI 尝试提取；文本层缺失（扫描件）→ 如实报告无法转换 |
| 粘贴内容 | 直接作为正文 |

转换后统一为干净 Markdown：标题层级完整、代码块带语言标记、空白折叠为单空格。

## 步骤 2 — 归属判定与落盘

**先判归属**（按序，不猜）：

1. 内容属于某个项目（提到项目名/路径/该项目的技术细节）：
   - **已入库** → `<KB_ROOT>/projects/<project_id>/docs/<文档名>.md`
   - **未入库** → 与记忆一致：先按 `code-project.md` 建档（add），再落项目 `docs/`；不愿建档则问用户
2. 跨项目 / 通用 / 平台文档 → `<KB_ROOT>/docs/<文档名>.md`
3. 判断不了 → **问用户**，不自行落通用 docs/

> 边界：**项目自己的分析/方案/报告** → `projects/<id>/docs/`；**跨项目或平台通用** → `docs/`。
> 判据：换一个项目还用得上吗？用得上 → `docs/`；只对这个项目成立 → 项目 `docs/`。

- 文件名 = 标题的英文/拼音短名，或直接保留原名（含中文）；中文目录/路径合法，不强制转写
- 多文件文档集 → `<归属目录>/<文档集名>/…`（保留原始层级）
- 排序：**用户指定 > 内容归属 > 内容主题**；不搞多层目录

## 步骤 3 — frontmatter

```yaml
---
title: "<文档标题>"
type: doc
source: "<本地绝对路径 | URL | 会话产出>"
date_added: "YYYY-MM-DD"
doc_version: "<可选：官方版本号，如 1.3.1；刷新时同步>"
date_updated: "<可选：最近一次回源核对的日期>"
aliases:                 # 可选：用户可能用的俗称，命中即置顶
  - <2~12 字的说法>
tags:
  - docs
---
```

**`doc_version` / `date_updated` 用来判断过时。** AirScript、Univer、GitHub Actions 这类文档会随版本变，
光看 `date_added` 只能知道"什么时候存进来的"，不知道"存的是哪一版、有没有跟上"。
不要求回填存量（现有 61/409 有），**refresh 时顺手补**即可。

**文档不写 `description`。** 卡片能检索的内容 = 标题 + 正文首段摘要 + 小节标题，
标题本身就是内容词（`Record` / `Facade API` / `OKR 基础知识手册`），再加一句 description 是重复。
记忆才必须有 description——它的文件名是 slug（`ask-before-push.md`），标题看不出内容。

正文开头不加装饰 callout。来源信息已在 frontmatter。

### 结构完整性（不设字数阈值，看结构）

转换完扫一遍，命中以下特征**报告给人判断**，不硬拒：

- [ ] 正文有至少一个非标题、非表格、非代码块的段落？
- [ ] 正文主体不是"首页/目录/上一篇/下一篇"这类导航文字？
- [ ] 没有 HTML 标签残留、乱码、重复的 cookie 声明？
- [ ] 标题与正文明显匹配（没有抓到跳转后的别的页面）？

字数不是质量代理——短章节（一个字段说明 300 字）也可能是完整文档。

### 写入自检（每次写文档必须过一遍）

- [ ] frontmatter 四字段齐全：`title` / `type: doc` / `source`（来源路径、URL 或"会话产出"）/ `date_added`
- [ ] 已判归属：项目产出物在 `projects/<id>/docs/`，通用才在 `docs/`
- [ ] 已查重：同 `source` / 同标题没有已存在文档，否则走刷新
- [ ] 结构完整性四条没有异常（有异常已向用户报告）
- [ ] 正文无残留 HTML 标签、无乱码
- [ ] 文件名与目录名可用中文；同一文档集内保持一种命名风格，不混用中英译名

## 资源处理（文档带图片/附件）

- 图片复制到**归属目录**下的 `assets/`（与文档同级；多文件文档集用 `<集名>/assets/`）
- 正文链接改**相对路径**：`![](assets/xxx.png)`；不保留指向库外的绝对路径
- 重名文件加后缀，**不覆盖**已有
- 非文本附件（pdf 等）复制原文件，不做转换

## 批量导入（目录）

路由命中「目录，纯文档」时：

1. 递归读取，保留原始层级 → `<归属目录>/<目录名>/…`
2. 每个 `.md` 按单篇转换并补 frontmatter（`source` 写原始路径）
3. 图片随 `assets/` 复制（见上）
4. 目录归属同样适用「归属判定」；判断不了先问用户
5. 完成报告（见下）

## 步骤 4 — 写与校验

1. 读 `templates.md` 模板，写文件。
2. 校验：文件存在、frontmatter 字段齐全、结构完整性无异常、正文无残留 HTML 标签/乱码。
3. 跑 `python3 <技能目录>/tools/kb-check.py`，退出码非 0 → 修完再报成功。

## 刷新（refresh <名>）

**只在用户明确要求时执行**。步骤：

1. 读取 `source`（网页抓一次 / 本地文件重读）；抓不到就如实报告，不猜内容。
2. 与本地正文比对，给出**差异摘要**（版本号、章节增删、接口签名变化），不要直接覆写。
3. 用户确认后才写：
   - 旧版先移入 `<KB_ROOT>/archive/docs/<主题>/<文档名>.md`（只归档不删除）；
   - 覆写正文，保留 frontmatter；`local_edits: true` 的文档先提示「这篇有本地加工」；
   - 更新 `last_checked`（回源日期）、`date_updated`；源版本变了同步改 `doc_version`。
4. 用「只记结论」时：不改正文，只在正文末尾追加一节 `## 核对记录 <YYYY-MM-DD>`。

## 完成报告

汇报 **added / updated / skipped**（含理由），附本次导入的文件数与归属目录：

```
added   3 篇 → docs/Univer Sheets/
updated 1 篇（源站已更新到 1.4.0）
skipped 2 篇（登录页无正文；与现有文档同 source）
```

「什么都没写」也是合法结果——说明跳过原因即可。
